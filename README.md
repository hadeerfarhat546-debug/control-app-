# نظام حساب الكنترول — نسخة برنامج سطح المكتب 🖥️

برنامج Windows حقيقي مبني على Electron من ملف الـ HTML الأصلي.
بيشتغل من غير إنترنت، وفيه نافذة حفظ Windows أصلية عند التصدير.

## خطوات التشغيل (أول مرة بس)

### 1️⃣ نزّل Node.js
- روح على https://nodejs.org ونزّل نسخة **LTS** وثبّتها (دوس Next لحد الآخر)

### 2️⃣ فك الضغط وفتح الطرفية
- فك الضغط عن الفولدر `control-app`
- دوس Shift + كليك يمين جوه الفولدر ← **Open in Terminal** أو **افتح نافذة الأوامر هنا**

### 3️⃣ نزّل المكتبات (محتاج إنترنت مرة واحدة بس)
```
npm install
```

### 4️⃣ شغّل البرنامج
```
npm start
```

## إنشاء ملف التثبيت (Setup.exe) للتوزيع 📦
```
npm run dist
```
- هتلاقي ملف التثبيت جوه فولدر `dist`
- ده ملف Setup زي أي برنامج — تقدر تنزله على أي لابتوب تاني وتبعته لزمايلك

## ملاحظات
- المكتبات (xlsx, jszip) بتتنزل محلياً جوه الفولدر — البرنامج بيشتغل أوفلاين 100%
- كل الأزرار الأربعة شغالة: إعادة التسمية، الإحصائيات، الملف النهائي، الترانسكريبت المحسوب
- أول مرة هتفتح عندك نافذة SmartScreen — دوس **More info ← Run anyway** (ده طبيعي لأن البرنامج مش موقع عليه رقم معتمد)
